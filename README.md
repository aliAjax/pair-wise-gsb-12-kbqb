# 校车接送点名台

由车辆调度小工具升级而来的早晚接送点名应用：调度员按线路排校车、司机和到离校时刻，跟车员逐站核对学生往返状态，异常情况走家长交接确认。

- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能闭环

### 调度排班
- 维护线路的校车车牌、司机、跟车员、准载人数，以及早接发车/到校、晚送离校/到家时刻和途经站点。
- **冲突检测**：同一校车或司机在重叠时段只能跑一趟，保存时硬阻止并列出冲突明细。
- **准载控制**：准载调小或加人超员时，多出来的学生自动退回「待定名单」，由调度员单独处理。

### 学生名册
- 登记学生班级、上下车站点、家长姓名与电话，可直接排入线路或标记为待定。
- 学生可在不同线路间调整，满员线路无法再排入。

### 点名台
- 按日期、线路、趟次（早接 / 晚送）点名，**依次核对**：
  - 早接：上车 → 到校
  - 晚送：返程上车 → 到家
- 每个环节可登记「正常 / 缺席 / 错站」；前序环节未处理不能跳过，异常后后续环节自动免核对。
- 缺席或错站必须写清**交给了哪位家长及原因**，生成交接记录，确认前学生保持「待确认交接」。
- **没有确认交接的学生不算完成**；可重置某学生单趟记录重新核对。
- 支持选择过去日期补录。

### 交接与待办
- 未完成事项（点名未走完、交接未确认）按日期留存，第二天打开会默认进入待办页，可一键跳回对应趟次继续处理。
- 交接记录支持按「待确认 / 已确认」筛选，可就地确认交接。

## 数据存储

数据保存在浏览器 localStorage，四类数据**分开保存**：

| key | 内容 |
| --- | --- |
| `dfwlfront-3-routes` | 线路排班 |
| `dfwlfront-3-students` | 学生名册 |
| `dfwlfront-3-attendance` | 点名记录（日期 + 线路 + 趟次 + 学生） |
| `dfwlfront-3-handovers` | 家长交接记录 |

首次打开会写入演示数据（含一条昨天的未完成点名与待确认交接），用于演示次日续处理。清除浏览器存储后恢复演示数据。后续可平滑替换为接口和权限体系。
