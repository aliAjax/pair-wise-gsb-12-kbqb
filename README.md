# 校车接送点名台

由车辆调度小工具改造的校园早晚接送点名工具。

- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- **线路调度**：按线路排校车、司机、跟车员和到离校时刻；同一校车或司机在重叠时段（早接/晚送两个窗口）只能跑一趟，冲突会被拦截并提示与哪条线路重叠。
- **学生名册**：登记学生并安排线路；准载不够时学生自动进入「待定」名单，有空位后可补位。
- **跟车点名**：跟车员按 上车 → 到校 → 返程上车 → 到家 依次核对；缺席或错站必须登记交接给哪位家长及原因，登记后该生后续环节终止。
- **交接与待办**：交接需确认，没有确认交接的学生不算完成；未完成点名跨天保留，第二天打开可接着处理。

## 数据存储

四类数据分开保存在浏览器 localStorage：

| 数据 | 键 |
| --- | --- |
| 线路 | `schoolbus-routes` |
| 学生 | `schoolbus-students` |
| 点名 | `schoolbus-attendance` |
| 交接 | `schoolbus-handovers` |
